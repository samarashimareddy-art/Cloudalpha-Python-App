# Cloudalpha-Python-App

Python use case for the AI DevOps Platform demo: a small FastAPI service with unit tests and a
Dockerfile. The CI/CD pipeline is generated by the platform from a plain-English request.

| Endpoint | Response |
|---|---|
| `GET /health` | `{"status":"ok","version":"1.0.0"}` |
| `GET /api/greeting?name=Raj` | `{"message":"Hello, Raj!"}` |

## Run locally

```bash
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
ruff check .                                      # lint
pytest                                            # unit tests
uvicorn app.main:app --reload                     # http://localhost:8000/health
```

```bash
docker build -t cloudalpha-python-app .
docker run -p 8000:8000 cloudalpha-python-app
```
